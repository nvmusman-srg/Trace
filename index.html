Four things hiding in your files

📍

Where you were

Phone photos embed GPS down to a few metres. A single picture can pin your home, campus, or workplace on a map.

📷

What you used

Exact camera or phone model, lens, settings — and often a unique camera serial number that links every photo you take.

🪪

Who you are

Documents record the author and “last modified by” names. Submit a file someone else wrote and it can show whose it really was.

🕓

When, exactly

Creation and edit timestamps to the second, plus total editing time — enough to reconstruct a timeline of when you worked.

How to strip metadata yourself

For images, the Strip & download button above does it instantly. Here is how to do it by hand on each platform, including for documents.

📱

iPhone / iPad

  1. Open Photos, pick the image, tap Share.
  2. At the top, tap Options and turn Location off before sharing.
  3. To wipe it permanently: tap the ⓘ info button → Adjust → remove location.
  4. Tip: Settings → Privacy → Location → Camera → set to “Never” to stop tagging new photos.
🤖

Android

  1. Open the photo in Google Photos, swipe up for details.
  2. Tap Edit location → No location to remove it.
  3. Prevent future tags: Camera app → Settings → turn off Location tags / Save location.
  4. Files app → long-press → Details also shows what is stored.
🪟

Windows

  1. Right-click the file → Properties → Details tab.
  2. Click Remove Properties and Personal Information at the bottom.
  3. Choose Create a copy with all possible properties removed.
  4. Works for photos, PDFs, and Office files alike.
🍎

macOS

  1. Photos: select → Image → Location → Remove Location, then export.
  2. Any file via Terminal with exiftool:
  3. exiftool -all= photo.jpg
  4. Install it first: brew install exiftool.
📄

Word & PDF documents

  1. Word: File → Info → Check for Issues → Inspect Document, then remove document properties and personal info.
  2. PDF: in Acrobat, Tools → Redact → Sanitize Document.
  3. Cross-platform: exiftool -all= file.pdf or qpdf to rewrite cleanly.
  4. Re-saving a Word file as PDF does not remove the author name.
🧰

The one tool to learn

  1. ExifTool is the standard for reading and wiping metadata on any file type.
  2. Read everything: exiftool file
  3. Strip everything: exiftool -all= file
  4. Batch a folder: exiftool -all= -r .
  5. Free, scriptable, and what forensics and OSINT folks actually use.
